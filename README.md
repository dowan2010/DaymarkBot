# 📓 Daymark — 뉴로우 회고 자동화 봇

Discord 슬래시 명령어 하나로 뉴로우 일일 회고를 AI가 자동으로 작성하고 제출하는 봇입니다.

---

## 🗂️ 파일 구조

```
├── index.js          # Discord 봇 진입점 — 슬래시 명령어 처리, 자동 회고 스케줄러
├── automation.js     # Playwright 브라우저 자동화 — 뉴로우 회고 제출 핵심 로직
├── crypto.js         # 사용자 이메일/비밀번호 암호화·복호화
├── lib/
│   ├── ai.js          # Vertex AI(Gemini) 회고/주제/감사 메시지 생성
│   ├── data.js         # users.json 읽기/쓰기 (제출 이력, 최근 주제 등)
│   ├── keys.js         # 활성화 키·플랜(free/pro/premium) 관리
│   ├── ui.js            # Discord Components V2 UI 빌더
│   └── webhooks.js      # 만료 알림 등 외부 웹훅 전송
├── Dockerfile         # 배포용 Docker 이미지 설정
├── .env               # 환경변수 (직접 생성 필요, Git 미포함)
├── users.json         # 등록된 사용자 데이터 (자동 생성, Git 미포함)
└── keys.json          # 활성화 키 데이터 (자동 생성, Git 미포함)
```

---

## ⚙️ 동작 흐름

```
사용자가 /회고 입력
  └→ 활성화 키 확인 (미활성화 시 차단)
       └→ Vertex AI(Gemini)로 회고 내용 생성
            └→ Playwright로 뉴로우 브라우저 자동화
                 ├→ 로그인
                 ├→ 자가 점검 자동 처리
                 ├→ 하루 돌아보기 자동 처리
                 ├→ 회고 주제 입력
                 ├→ 자유형 선택
                 ├→ 회고 내용 입력 및 제출
                 ├→ 공유하기
                 └→ 감사 카드 작성 → Discord에 결과 표시
```

과거 날짜(`날짜` 옵션)로 회고를 제출할 경우 주말 차단과 "이미 진행 중" 차단 모두 예외 처리되어, 오늘 회고를 진행하면서 동시에 과거 날짜 회고도 별도로 제출할 수 있습니다.

## 🛠️ 사용 기술

| 기술 | 역할 |
|------|------|
| **Discord.js v14** | 슬래시 명령어 처리, Components V2 UI |
| **Playwright** | 브라우저 자동화 (뉴로우 사이트 조작) |
| **Gemini API (AI Studio)** | 회고 텍스트 자동 생성 — fetch 기반 직접 호출 |
| **p-queue** | 동시 처리 제한 |

## 🔑 환경변수 설명 (`.env`)

```env
DISCORD_TOKEN=          # Discord Developer Portal에서 발급한 봇 토큰
GEMINI_API_KEY=         # Google AI Studio에서 발급한 Gemini API 키
ENCRYPTION_KEY=         # 사용자 비밀번호 암호화 키 (임의 문자열)
ERROR_CHANNEL_ID=       # 오류 및 업데이트 알림을 전송할 채널 ID
ADMIN_USER_IDS=         # 관리자 Discord 유저 ID (쉼표로 구분, 예: 123,456)
HEADLESS=               # 브라우저 headless 모드 (로컬 테스트 시 false)
INTERNAL_SECRET=        # 내부 API 서버 인증 토큰 (선택)
INTERNAL_PORT=          # 내부 API 서버 포트 (기본값: 3001)
EXPIRY_WARNING_DAYS=    # 키 만료 임박 알림 기준일 (기본값: 3)
EXPIRY_LOG_WEBHOOK=     # 키 만료 로그 웹훅 URL (선택)
```

> ⚠️ `.env` 파일은 Git에 포함되지 않습니다. 직접 생성해서 사용하세요.

## 💬 Discord 슬래시 명령어

| 명령어 | 설명 |
|--------|------|
| `/회고` | 회고 자동 생성 및 제출. 주제/날짜 옵션 지정 가능 |
| `/회고일괄` | 날짜 범위를 지정해 여러 날의 회고를 한 번에 순차 제출 (프리미엄, 최대 14일) |
| `/회고초기화` | 작성 중인 회고를 초기화 (날짜 옵션으로 특정 날짜 지정 가능) |

| `/히스토리` | 나의 회고 제출 히스토리를 달력으로 확인 |

| `/계획하기` | 할일을 선택해 캘린더에 일정 등록 |
| `/설정` | 봇 설정 변경 (자동 회고 시각 등) |
| `/등록` | 뉴로우 이메일·비밀번호 등록 |
| `/변경` | 등록된 이메일·비밀번호 변경 |
| `/내정보` | 현재 등록된 이메일 확인 |
| `/삭제` | 등록된 계정 정보 삭제 |
| `/감사카드` | 감사 카드 수신자·메시지 저장 (회고 시 자동 적용) |
| `/주제추천` | AI가 오늘 공부할 주제 3개 추천 |
| `/대기` | 현재 회고 대기 중인 인원 수 확인 |
| `/키입력` | 구매 후 발급받은 활성화 키 입력 |
| `/사용법` | 봇 사용 방법 안내 (활성화 키 없이도 사용 가능) |

> `/사용법`을 제외한 모든 명령어는 **활성화 키**가 필요합니다.

## 🕐 자동 회고 (프리미엄)

`/설정`에서 지정한 시각에 평일 자동으로 회고를 생성·제출합니다. 제출 5분 전 리마인더 DM이 전송되며, 실패 시 최대 2회까지 자동 재시도합니다. 완료/오류 결과는 DM으로 안내됩니다.

---

## 🔐 활성화 키 시스템

신규 사용자는 관리자에게 활성화 키를 발급받아야 봇을 사용할 수 있습니다.

1. 관리자에게 활성화 키 요청
2. 아무 명령어 입력 시 **키 입력하기** 버튼 클릭 (또는 `/키입력`)
3. 발급받은 7자리 키 입력 → 활성화 완료
4. `/등록`으로 뉴로우 계정 등록 후 사용

플랜은 `free < pro < premium` 순으로, 일부 명령어(`/회고일괄`, `/통계`, 자동 회고 등)는 pro 이상 플랜이 필요합니다.

## 🛡️ 관리자 명령어 (`!`)

`ADMIN_USER_IDS`에 등록된 유저만 사용 가능합니다. **DM에서만** 동작합니다.

| 명령어 | 설명 |
|--------|------|
| `!` 또는 `!명령어` | 명령어 목록 보기 (어디서든 사용 가능) |
| `!키발급 [수량]` | 활성화 키 발급 (기본 1개, 최대 10개) |
| `!키목록` | 미사용 키 목록 확인 |
| `!계정조회` | 등록된 전체 계정 목록 |
| `!유저검색` | 드롭다운으로 유저 선택 후 계정 조회 |
| `!계정검색 <이메일>` | 이메일로 계정 검색 |

## 🚀 로컬 실행 방법

### 1. 의존성 설치
```bash
npm install
npx playwright install chromium
```

### 2. `.env` 파일 생성
위 환경변수 설명을 참고해서 `.env` 파일을 직접 작성하세요.

### 3. 실행
```bash
node index.js
```

> 브라우저 창을 보면서 테스트하려면 `.env`에 `HEADLESS=false` 설정

## 📝 커밋 메시지 규칙

| 접두사 | 의미 | Discord 알림 |
|--------|------|-------------|
| `feat:` | 새 기능 추가 | ✅ 알림 전송 |
| `fix:` | 버그 수정 | ✅ 알림 전송 |
| `chore:` | 설정·개선 | ✅ 알림 전송 |

## ⚠️ 주의사항

- `users.json`, `keys.json`, `.env`는 Git에 포함되지 않습니다 — 직접 관리하세요
- 뉴로우 UI가 변경되면 `automation.js`의 선택자 수정이 필요할 수 있습니다
- `automation.js`는 매 호출마다 새 브라우저를 실행합니다 — 세션 파일을 저장하지 않고 항상 새로 로그인합니다
